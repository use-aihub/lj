# 严重程度与退回条件

## 严重程度

- **重大**：影响项目范围、评价等级、敏感目标、监测/预测可靠性、达标结论、审批或验收。
- **较大**：关键参数、局部预测或跨文件矛盾明确，可通过有限补正闭合，但不处理会削弱结论。
- **一般**：局部数据、表述、措施或引用错误，不改变整体结论。
- **文字**：项目名称、错字、编号、单位、表图引用等可直接确定的文字问题。

## 重大退回条件

命中任一项，总体结论写“建议退回修改后复核”：

- 预测或监测结果超标，正文却判定达标；表、图、文字结论矛盾并影响达标判断。
- 项目组成、评价范围、线路路径、站址或敏感目标存在重大遗漏、错用或无法闭合。
- 核准、可研/设计、关键专题、附图、监测报告或原始记录缺失，导致关键结论不能验证。
- 监测时间、天气、点位、频次、仪器或运行工况存在硬错误，数据不能支撑评价。
- 电磁预测额定负荷、导线/塔型/线高、类比代表性或噪声源强、距离、屏障、昼夜叠加存在系统性错误。
- 电磁、噪声、生态、水保、防洪等关键预测/计算缺失，或遗漏会改变结论的工程内容。
- 事故油池有效容积、事故油坑、油水分离、防渗防雨、危废暂存/转移/处置无法闭环。
- 专家意见、批复要求或重大限制条件未落实，回复却写“已修改”。
- 生产建设项目未在开工前依法完成水土保持方案编报审批，且未提供主管水行政部门处理、整改及闭合材料，报告却作出水土保持设施验收合格结论。

## 较大及升级规则

以下问题通常列“较大”；多项叠加、波及多个对象或改变结论时升级为“重大”：

- 主变容量、线路长度、杆塔、导线、最低线高、评价范围等关键参数跨文件不一致。
- 改扩建、间隔完善、迁改或并行线路列入建设内容但局部未评价。
- 跨越净距、预测输入、环保投资、占地、恢复面积或事故油计算存在明确局部错误。
- 环保措施不可施工、不可运行、不可验收，或水保/防洪/生态限制条件未落到措施。
- 法规、标准或导则版本错误并影响评价判断。

证据不足但风险较高时，不臆定重大事实；写“审查受限”，列明唯一必要补充材料和取得材料后的闭合处理分支。

问题批注、文件级严重程度分布和总体结论必须一致，禁止出现重大批注却给出“可修改后复核”。
